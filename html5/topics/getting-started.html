Getting Started

To get started, edit the DITA sources under src/topics and update the map at src/maps/main.ditamap.

Build the documentation locally with the DITA-OT command line using the HTML5 and PDF targets.

Local build commands

Run these commands from the repository root:


        dita -i src/maps/main.ditamap -f html5 -o out/html
        dita -i src/maps/main.ditamap -f pdf2 -o out/pdf
